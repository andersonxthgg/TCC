# 🐍 PlayCode

 Desenvolvi essa plataforma web para o ensino de lógica de programação e introdução ao JavaScript é proximamente outras linguagens.

---

## Tema do projeto 📝

O **PlayCode** é um projeto voltado para a área da educação, ele é inspirado em plataformas de aprendizado como o Duolingo, o sistema foi desenvolvido para tornar o ensino de programação mais acessível, interativo e intuitivo para iniciantes. Agora de inicio a plataforma irá trazer lições práticas e exercícios focados no básico de **JavaScript**. No entanto iremos trazer mais linguagens na plataforma

## Problema

O mercado na Área da tecnologia vai crescendo rapidamente e exige cada vez mais profissionais qualificados. Porém, o ensino tradicional de programação ainda possui dificuldades para iniciantes na área com sintaxes complexas e métodos muito teóricos, causando frustração e desistência nas pessoas que tentam evoluir. É muitos softwares educacionais são pouco dinâmicos para os usuarios.


## Objetivo
O nosso objetivo é desenvolver uma plataforma web que combine o engajamento dos jogos com uma estrutura gamificada para tornar o aprendizado de lógica e JavaScript mais simples e intuitivo, com uma estrutura escalável para adicionar novos módulos de ensino.

## Justificativa

A plataforma PlayCode busca facilitar o acesso ao ensino de programação por meio da gamificação para deixar o aprendizado mais simples, interativo e acessível para a comunidade de programação iniciante.

## Público-Alvo

Iniciantes que desejam aprender lógica de programação e JavaScript isso inclui:
- estudantes
- entusiastas de tecnologia
- pessoas em transição de carreira e instituições de ensino que buscam ferramentas acessíveis de apoio ao aprendizado.

## Funcionalidades Principais

* **Lições Dinâmicas:** Conteúdos teóricos divididos em partes pequenas para facilitar o aprendizado.

* **Exercícios Interativos:** Correção automática e instantânea de quizzes e respostas em texto.
  
* **Interface Intuitiva:** Layout simples e organizado para facilitar a navegação e o uso da plataforma.


## Relação com as ODS (ONU) 🎯

O projeto contribui para a **ODS 4: Educação de Qualidade**, especificamente com a **Meta 4.4**, que visa em aumentar o número de jovens e adultos com habilidades técnicas relevantes para o mercado de trabalho no caso desse projeto na área da tecnologia.
